# Calcul du nombre de trajet par jour de la semaine

Calcul du nombre de trajet par jour de la semaine

## Usage

``` r
calcul_distribution_semaine(trajet, filtre = TRUE)
```

## Arguments

- trajet:

  tibble. Données de trajets

- filtre:

  logical. Appliquer le filtre sur les anomalies

## Value

tibble. Données de comptage.
